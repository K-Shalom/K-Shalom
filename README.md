## 🏆 Featured Project

### 🏪 SmartBiz — Smart Small Business Management System

A full-stack, production-ready web application that helps small businesses manage products, services, clients, sales, expenses, and generate PDF reports — secured with JWT authentication and role-based access control.

<p align="left">
  <img src="https://img.shields.io/badge/Status-Deployed-brightgreen?style=flat-square" />
  <img src="https://img.shields.io/badge/Auth-JWT%20%2B%20RBAC-orange?style=flat-square" />
  <img src="https://img.shields.io/badge/Reports-PDF%20via%20iText-red?style=flat-square" />
</p>

| Layer | Technology |
|---|---|
| **Backend** | Spring Boot 3.5 · Java 21 · Spring Security 6 · JWT |
| **Frontend** | HTML5 · Bootstrap · Vanilla JS · Chart.js · Fetch API |
| **Database** | MySQL 8 · JPA / Hibernate |
| **Reports** | iText 5 · PDF generation |
| **Deployed** | Netlify (Frontend) · Render (Backend) |
